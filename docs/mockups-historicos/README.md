# Mockups históricos

Exploración de diseño visual (paleta "Clinical Precision" + prototipo HTML
estático con Tailwind por CDN) del 22/07, hecha para explorar dirección
visual del vertical médico/rehab. No es código del proyecto — nada lo
importa ni lo referencia. Se guarda como referencia histórica, no como
fuente de verdad de diseño actual.

- `DESIGN.md` — tokens de color de la paleta explorada.
- `code.html` — prototipo estático, standalone (no corre con Vite/el resto del repo).
- `screen.png` — captura del prototipo.
